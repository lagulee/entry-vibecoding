# GRAVITY LAB — 전체 블록 목록 (자동 생성)

`tools/build_gravity_lab.js` 가 만든 작품의 모든 스크립트를 엔트리 블록 문구로 옮긴 것입니다.
표기: `[명령 블록]` · `(값 블록)` · `<판단 블록>` · 들여쓰기 = 블록 안쪽에 끼워 넣기, `[아니면]` = 만약-아니면 블록의 아래칸.
